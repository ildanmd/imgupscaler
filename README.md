# 이미지 화질 개선 (브라우저 버전)

설치 없이 웹페이지에서 바로 돌아가는 AI 업스케일 도구입니다.
사진은 서버로 올라가지 않고, 보는 사람의 브라우저 안에서 처리됩니다.

## 내 컴퓨터에서 먼저 열어 보기
`index.html`을 더블클릭하면 동작하지 않습니다(브라우저 보안 규칙). 아래 둘 중 하나로 여세요.
- Windows: `run-local.bat` 더블클릭 (Python 필요) → http://localhost:8000
- 그 외: 이 폴더에서 `python3 -m http.server 8000`

## 인터넷에 올리기
이 폴더를 통째로 정적 호스팅에 올리면 끝입니다. 서버 프로그램이 필요 없습니다.
- GitHub Pages: 레포지토리에 이 폴더 내용을 올리고 Settings → Pages에서 켜기
- Netlify: 폴더를 드래그해서 올리기 (`_headers` 파일이 CPU 모드를 더 빠르게 해 줍니다)

## 폴더 구성
- `index.html` 화면과 동작 전부
- `models/` AI 모델 (약 5MB)
- `ort/` 브라우저에서 AI를 돌리는 엔진 (약 29MB, 처음 한 번만 내려받음)
- `_headers` 일부 호스팅용 설정 (없어도 동작)
- `LICENSES.txt` 모델·엔진 라이선스 표기

## 알아둘 점
- 크롬·엣지 최신 버전에서 그래픽카드(WebGPU)로 처리합니다. 지원하지 않는 브라우저는 CPU로 처리해서 느립니다.
- 입력은 긴 변 2000px, 20MB까지. 투명 배경은 흰색으로 채워집니다.
- 2배는 4배로 키운 뒤 절반으로 줄여서 만듭니다.
